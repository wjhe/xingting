## 一、我们如何收集和使用您的个人信息

### （一）我们如何收集您的个人信息

在您使用问道长生过程中，我们会按照如下方式收集您的个人信息：

**1. 登录游戏**

本游戏不设独立的账号系统，使用 TapTap 账号登录。当您登录问道长生时，我们通过 TapTap 提供的 TapSDK 收集您 TapTap 账号的唯一标识（OpenID）、昵称、头像。我们收集您的上述信息是为了识别您的身份、将您的游戏存档与账号关联，并在 TapTap 账号体系中保持登录状态。如您不提供这类信息，您将无法登录问道长生。

**2. 游戏服务**

当您使用游戏服务时，我们通过 TapSDK 收集您使用的设备 ID、设备名称、设备类型和版本、操作系统版本、设备 CPU 信息、设备内存信息、网络类型。我们收集您的上述信息是为了保障您正常使用我们的服务，维护游戏基础功能的正常运行，优化游戏产品性能，提升您的游戏体验。如您不提供这类信息，您将无法使用游戏服务。

您的游戏存档（角色、境界、物品、设置等）**仅保存在您的设备本地**，我们不上传、不收集，也无法查看。

**3. 实名认证**

当您进行实名认证时，我们通过 TapTap 的合规认证服务核验您的真实身份。**我们不收集、不保存您的姓名和身份证件号码**：认证过程由 TapTap 及国家新闻出版署网络游戏防沉迷实名认证系统完成，我们仅收到认证结果以及基于实名信息的年龄段判断（是否为未成年人）。我们收集上述信息是为了履行法定义务，核验用户真实身份、识别用户年龄以及落实防沉迷要求。如您不提供上述信息，您将无法登录问道长生。

**4. 保障网络和服务的安全**

为了保障网络和游戏服务的安全性，我们通过 TapSDK 收集您的设备识别符（Android ID）、IP 地址、访问日期和时间。我们收集您的上述信息以营造公平、健康及安全的游戏环境。如您不提供上述信息，您将无法使用游戏服务。

**5. 广告服务**

问道长生提供**可选**的激励视频广告与插屏广告。只有在您主动选择观看时，广告才会播放。为投放广告、统计展示与点击、归因与反作弊，第三方广告 SDK（TapADN）会收集您的设备标识符（Android ID、OAID）、IP 地址、设备品牌、型号、系统版本、屏幕分辨率与密度、设备语言、时区、CPU 信息、可用存储空间、网络类型、应用包名与版本号、应用前后台状态、广告交互数据以及崩溃与性能数据。详细清单见本政策第五条。

您可以在"角色 > 设置 > 个性化广告"中随时关闭个性化广告。关闭后广告数量不会减少，但广告与您的相关度会降低。

**6. 充值消费**

**问道长生不提供任何付费内容**，游戏内不存在充值、内购或虚拟货币交易。我们不收集您的支付信息，也不需要任何支付相关的权限。

### （二）设备权限调用情况

在您使用问道长生过程中，我们需要在必要范围内向您申请获取设备权限。请您知悉，我们不会默认开启您设备的权限，仅在您主动确认开启的情况下，问道长生才有可能通过设备权限收集您的信息。问道长生调用的权限、调用权限的目的，以及调用权限前向您询问的情况请见下表：

| 设备权限 | 调用权限的目的 | 是否询问 | 用户可否关闭权限 |
| --- | --- | --- | --- |
| 网络 | 连接网络，完成登录、实名认证与广告加载 | 是 | 可 |
| 获取网络状态 | 判断网络是否可用，给出相应提示 | 是 | 可 |
| 安装应用 | 仅在您主动点击应用下载类广告中的"下载"后会用到，由系统询问 | 是 | 可 |

**问道长生不申请**相机、相册、麦克风、通讯录、位置、短信、日历、传感器等权限，**不读取**您的剪切板内容。

如您在首次授权开启权限后希望关闭权限，您可以在设备的设置功能中选择关闭权限，从而拒绝我们收集相应的个人信息。

### （三）我们如何使用您的个人信息

我们会根据本政策的约定并为实现我们的服务的目的对所收集的个人信息进行使用。

请您注意，您在使用我们提供的服务时所提供的所有个人信息，除非您删除或通过系统设置拒绝我们收集，否则将在您使用我们的服务期间持续授权我们使用。

我们会对我们提供的服务使用情况进行统计，但该统计**仅基于存放在您设备本地的数据**，不会形成可识别到您个人的信息，也不会与任何第三方共享。

当我们要将您的个人信息用于本政策未载明的其它用途时，或基于特定目的收集而来的信息用于其他目的时，会通过您主动做出勾选的形式事先征求您的同意。本政策内容发生变更时，我们会在游戏启动时重新向您展示并征求同意。

### （四）其他规则

根据相关法律法规及国家标准，以下情形中，我们可能会收集、使用您的相关个人信息而无需征求您的授权同意：

- 与我们履行法律法规规定的义务相关的；
- 与国家安全、国防安全直接相关的；
- 与公共安全、公共卫生、重大公共利益直接相关的；
- 与刑事侦查、起诉、审判和判决执行等直接相关的；
- 出于维护个人信息主体或其他个人的生命、财产等重大合法权益但又很难得到本人授权同意的；
- 所涉及的个人信息是个人信息主体或监护人自行向社会公众公开的；
- 根据个人信息主体要求签订和履行合同所必需的；
- 从合法公开披露的信息中收集个人信息的，如合法的新闻报道、政府信息公开等渠道；
- 维护所提供产品或服务的安全稳定运行所必需的，如发现、处置产品或服务的故障。

### （五）我们明确不收集的信息

为避免误解，我们特别说明：问道长生**不收集**您的姓名与身份证件号码（由 TapTap 处理）、手机号码、通讯录、短信、位置信息、相册与相机内容、麦克风录音、剪切板内容、生物识别信息、您在其它应用中的使用记录、已安装应用列表。

问道长生没有聊天、组队、好友、排行榜等社交功能，因此**不收集任何您与其他玩家之间的交互内容**。

## 二、我们如何保存您的个人信息

### （一）保存期限

我们将在本政策载明的目的所需及法律法规要求的最短保存期限之内，保存您的个人信息。前述期限届满后，我们将对您的个人信息做删除或匿名化处理。

您的游戏存档保存在您的设备本地，保存期限取决于您何时删除它——卸载游戏或清除应用数据即被删除，且无法恢复。第三方 SDK 收集的信息由其按照自身隐私政策保存，我们不为这些信息建立数据库，也不保留副本。

### （二）保存地域

我们在中国境内运营过程中收集和产生的个人信息将保存在中国境内（为本隐私政策之目的，"中国境内"不含中国港澳台地区），以下情形除外：

- 法律有明确规定；
- 获得您的明确授权；
- 您要求获取境外服务等个人主动行为。

针对以上情形，我们会确保依据本隐私政策以及相关法律规定对您的个人信息提供足够的保护。本游戏不向境外提供个人信息。

## 三、我们如何使用 Cookies 和同类技术

问道长生是原生移动应用，**不使用 Cookie，不使用任何第三方统计或追踪技术**。

为保存您的游戏存档、设置项以及广告次数记录，我们使用设备本地的存储能力（应用私有目录与 WebView 的本地存储 localStorage）。这些数据：

- 仅保存在您的设备上，不会上传到我们的服务器（我们没有自己的服务器）；
- 不会用于跨应用追踪您；
- 会在您卸载游戏或清除应用数据时被删除。

若您通过网页版访问本游戏，您的浏览器可能使用本地存储保存同样的数据，您可以随时通过浏览器设置清除。清除后您的游戏进度将丢失。

**我们不会向任何第三方出售您的个人信息。**

### （三）转让

我们不会将您的个人信息转让给任何公司、组织和个人，但在涉及合并、收购、资产转让或破产清算时，如涉及到个人信息转让，我们会向您告知有关情况，并要求新的持有您个人信息的公司、组织继续受本政策的约束，否则我们将要求该公司、组织重新取得您的授权同意。

### （四）公开披露

除本政策另有约定或法律明确规定，我们不会公开披露您的个人信息。

### （五）例外情况

另外，根据相关法律及国家标准，以下情形中，我们可能会共享、转让、公开披露个人信息无需事先征得您的授权同意：

## 六、我们如何保护您的个人信息

我们非常重视个人信息安全，并采取一切合理可行的措施，保护您的个人信息：

- **最小必要**：只接入服务所必需的 SDK，并按最小必要原则逐项配置其信息采集开关。位置、电话状态、Wi-Fi、MAC、传感器、应用列表等采集项均已关闭，"摇一摇"互动已禁用。
- **同意前置**：所有第三方 SDK 只在您同意本政策后才初始化。
- **安装包校验**：接入的广告 SDK 安装包经 MD5 与官方发布值核对后才使用。
- **权限最小化**：仅申请网络相关权限；广告 SDK 自带的"读取应用列表"权限已在应用清单中移除。
- **数据本地化**：游戏存档不离开您的设备，我们无从访问，也就无从泄露。

请您知悉，虽然我们将尽力确保您发送给我们的任何信息的安全性，但互联网环境并非百分之百安全。

在不幸发生个人信息安全事件后，我们将按照法律法规的要求，及时向您告知：安全事件的基本情况和可能的影响、我们已采取或将要采取的处置措施、您可自主防范和降低风险的建议、对您的补救措施等。我们将及时将事件相关情况以应用内公告等方式告知您。同时，我们还将按照监管部门要求，主动上报个人信息安全事件的处置情况。

### （二）删除您的个人信息

在以下情形中，您可以通过本隐私政策载明的方式向我们提出删除个人信息的请求：

- 我们违反法律、行政法规或与您的约定收集、使用个人信息；

您也可以直接卸载问道长生或在系统设置中清除本应用的数据，这将删除保存在您设备上的全部游戏数据。
