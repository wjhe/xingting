# 星庭物语

原创竖屏女儿养成游戏，参考经典日式养成游戏的日程与成长玩法。当前为可完整游玩的手机网页版，从 10 岁培养到 18 岁，共 96 个月。

下一阶段的界面、美术、换装、剧情和声音升级见 [开发计划](星庭物语开发计划.md)。计划内容与下方当前已实现功能分开记录。

## 启动

```bash
npm install
npm run dev -- --host 0.0.0.0
```

建议使用 `npm run dev -- --host 0.0.0.0 --port 5174 --strictPort`，电脑打开 http://localhost:5174/ 。手机与电脑连接同一 Wi-Fi 后，打开 Vite 输出的 Network 地址。桌面保持竖屏游戏区域，页面支持触屏滚动。

## 当前玩法

- 每月三段日程，课程、打工、休息、探索共 18 种活动。
- 体力、智力、魅力、气质、武艺、品德六项能力，亲密度与压力。
- 80 个独立事件：24 个年度主线节点、20 个人物支线节点、16 个条件日常和 20 个早期生活事件；另有年度收获祭、生日与成长手账。
- 三处探索区域的自动交锋、逐步回放、安全撤退与额外战利品。
- 谈心、送礼、商店物品与服装购买；日常、夏装、冬装、礼服四种版型，三个年龄阶段适配，保留原有两种额外配色。
- 四位角色的连续支线与羁绊记录，早期选择在部分后续主线中得到回应。
- 11 种职业结局、跨周目收藏。
- 自动存档、格式校验、JSON 导入导出。
- 原创合成庭院旋律占位；两套 Kenney CC0 素材导出的八种交互与战斗音效，独立音量和开关。

## 开发与验证

```bash
npm run build               # 正式网页构建，产物 dist/
npm test                    # 含保留的原骨架测试
npm run test:raising        # 规则、存档与 100 局随机完整成长验证
npm run sim:raising -- 300  # 八年培养模拟，统计结局与压力
npm run smoke:raising      # Edge 操作与手机尺寸检查，先启动 dev
npm run smoke:raising:content # 全部事件、区域战斗和结局图引用检查
npm run assets:raising     # 保留 cel-v3 默认立绘及三色叠层
npm run assets:raising:production # BiRefNet 抠图、正式新素材及 CC0 音效导出
npm run catalog:raising    # 从实际内容更新事件与服装目录
```

新游戏独立模块位于 `src/raising/`：`game.ts` 为纯 TypeScript 逻辑，不依赖引擎、浏览器或系统时间；`content.ts` 为内容；`app.ts` / `style.css` 为触屏 UI；`stage.ts` 使用 Phaser 渲染画像与光尘，只用纹理，不使用 Graphics。限制 30 FPS。随机数复用 `src/core/rng.ts`。

本局存档键 `stargarden_save_v1`，跨周目收藏键 `stargarden_meta_v1`，与原项目存档互不影响。

本轮为兼容旧版本进行增量迁移：新增活动次数、人物关系及新主线起始月份。旧服装所有权保留；新服装按款式购买一次，各年龄适配款一并拥有。具体规格、素材和验收见 [开发推进记录](stargarden/开发推进记录.md)。

## 美术

正式采用用户确认的 `cel-v3` 赛璐璐测试图为基准，见 [美术规范](星庭物语美术规范.md)。幼年原图直接使用 `art-src/stargarden/style-tests/cel-v3.png`；成长立绘和城镇为 `art-src/stargarden/cel-v3/teen.png`、`town.png`。旧版源图保留对照。接口、模型、完整提示词与时间在 `art-src/generation_log.jsonl` 留档，密钥不进入版本库或网页产物。

提示词共同要求：authentic early 1990s Japanese fantasy daughter-raising character illustration; fine warm brown contour lines; flat opaque local colors; ONE sharply defined shadow tone per surface; restrained highlights; ivory, sage mint green and dusty rose; bright clean fresh; no glossy anime, airbrush glow, giant kawaii eyes, watercolor grain, sepia or text。

生成方式：用户指定的项目图像接口，经 `scripts/genimage.py` 与 `scripts/stargarden-produce.py` 调用。默认幼年、少年立绘保留获批源图与原三色叠层；新衣装、成长后立绘、活动、剧情、战斗、表情与结局素材位于 `art-src/stargarden/production-v1/`，运行文件在 `public/assets/stargarden/production-v1/`。

房间背景、透明人物和服装、演出效果与 UI 独立显示。复杂衣装用整套透明人物，原三色衣装继续使用配色叠层；人物不能只靠自动抠图拆出被衣服遮住的身体。新透明素材使用本地 BiRefNet ONNX 模型提取，原图、蒙版、处理参数与源图指纹留档。三个年龄阶段为 10–13、14–15、16–18 岁；表情以独立头像用于谈心与事件。界面由 `classic.css` 提供集中布局与经典游戏面板质感。

素材和声音说明：[抠图与音效方案](stargarden/抠图与音效方案.md)、[AI 音乐需求与提示词](stargarden/AI音乐需求与提示词.md)、[剧情与事件目录](stargarden/剧情与事件目录.md)、[服装目录](stargarden/服装目录.md)。七首正式背景音乐尚未生成，本轮交付完整需求与提示词。
