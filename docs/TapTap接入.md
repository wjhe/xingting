# TapTap SDK 接入说明

> 2026-10-31。接入 TapSDK v4.11.0 的 **TapTap 登录** 和 **合规认证（实名认证、防沉迷）**，只在安卓 APK 里生效；网页版、微信小游戏不受影响。
> 官方文档：https://developer.taptap.cn/docs/sdk/

## 一、玩家看到的流程

1. **首次打开**：《用户协议》《隐私政策》同意页（TapSDK 合规要求：玩家同意之前不初始化 SDK）。不同意可以退出游戏。
2. **TapTap 登录**：只请求 `basic_info`，装了 TapTap 客户端的玩家可以无感登录。
3. **实名认证与防沉迷**：只有回调 500 才能进入游戏。
   - 未成年人不在可玩时段（1030）、时长用尽（1050）、年龄不符（1100）：拦在门口并说明规定。
   - 网络异常（1200）、关掉实名窗口（9002）：可以重试。
   - 退出或切换账号（1000 / 1001）：回到登录页。
4. **游戏中途**收到限制（例如未成年人到点）：先存档，再停掉游戏、回到门口。
5. **退出登录**：角色 > 设置 > 「退出 TapTap 登录」（隐私政策里承诺了这个入口）。

## 二、需要你在 TapTap 开发者中心完成的

1. 创建游戏，进入 **游戏服务 > 应用配置**，点「立即开启」，地区选**中国大陆**。记下 **Client ID** 和 **Client Token**。
2. 填写安卓信息：
   - 包名：`com.wendao.changsheng`
   - 签名 MD5（正式签名）：`77fe553d53c72b1543c295fa00a43b12`（2026-10-31 换的密钥，旧密钥 `74e4ffc5b80af4f49a6910e6b3fa6ea6` 已归档在 `android-keys/archive/`）
   - 调试包签名不同（`df4e0bd7176c7260c8855666e09da9bb`）。开发者中心每个应用只认一个签名，建议另建一个测试应用填调试签名，或者测试时也用正式包。
3. **游戏服务 > TapTap 登录**：开通。
4. **游戏服务 > 合规认证**：开通，选「**暂无版号**」方案（拿到版号后再切换，并到中宣部系统注册）。
5. 合规认证页面里有**自测专用测试账号**（12 个，可设置可玩时段、年龄段），用它们测试未成年人限制。
6. 把隐私政策和用户协议（`src/data/legal.ts` 里的文字）发布到一个公开网址，填进商店后台。

## 三、把凭证交给打包脚本

在项目根目录的 `android-keys/` 里新建 `taptap.properties`（该目录不进版本库）：

```
clientId=你的 Client ID
clientToken=你的 Client Token
```

然后照常 `npm run build:android`。没有这个文件时，APK 只显示隐私政策同意页，不启用 TapTap 登录（方便没有凭证时测试）。

## 四、代码位置

| 内容 | 位置 |
|---|---|
| 原生插件（初始化、登录、登出、开始认证、合规回调转成事件） | `android/app/src/main/java/com/wendao/changsheng/TapTapPlugin.java` |
| 依赖与凭证读取 | `android/app/build.gradle` |
| 网页层接口、浏览器里的模拟实现 | `src/platform/taptap.ts` |
| 门口场景（同意页、登录、认证结果、中途踢出） | `src/render/scenes/GateScene.ts` |
| 用户协议、隐私政策（**草稿**，需填写【】并审阅） | `src/data/legal.ts` |

改了协议内容，把 `LEGAL_VERSION` 改成新日期，所有玩家会被要求重新同意。

## 五、测试

- 浏览器走查（不需要手机和凭证）：`npm run dev` 后运行 `node scripts/gate-check.mjs`。它通过 `localStorage.wdcs_fake_tap` 模拟 TapTap，覆盖同意、登录、未成年人拦截、中途踢出、退出登录、网页版直通。
- 手动模拟：在浏览器控制台设置 `localStorage.setItem('wdcs_fake_tap', '1030')`（值为要模拟的合规回调码）后刷新；进游戏后执行 `__fakeCompliance(1050)` 模拟中途时长用尽。
- 真机：配置凭证、打包安装后，用开发者中心的测试账号分别验证成年、未成年、未实名三种情况。

## 六、没有接的模块（按需再加）

更新唤起、云存档、成就、排行榜、TapTap 评价、内嵌动态、TapDB 数据分析、TapTap IAP。每加一个，都要在隐私政策里补上对应的收集信息（见官方《TapSDK 合规使用说明》）。

## 七、注意

- 合规回调必须在 `TapTapSdk.init` 成功之后再注册（插件在 `onInitSuccess` 里注册）。提前注册会被初始化覆盖：SDK 日志显示认证通过，游戏却一直停在「正在进行实名认证」。
- 真机测试记录（2026-10-31）：同意页 → 初始化 → TapTap 客户端无感登录 → 实名认证回调 500 → 进入游戏，全程正常。

- 现在的 APK 里，激励视频仍是模拟广告（见 [广告变现方案.md](广告变现方案.md)）。正式发布前要换成真实广告 SDK，并把它写进隐私政策第二节第 2 条。
- 若恶意绕过防沉迷，开发者承担法律责任且游戏会被下架。门口的判断不要为了测试方便而关掉，测试请用模拟或测试账号。
