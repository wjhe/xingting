# 星庭物语美术规范

正式画风为用户确认的 `cel-v3` 赛璐璐测试图：[基准原图](../art-src/stargarden/style-tests/cel-v3.png)。后续人物、年龄变化、衣装及场景统一以此图为准。

2026-11-01 起增加 `production-v1` 素材：独立版型夏装、冬装、礼服，三个年龄阶段、活动、事件、战斗、表情与结局插画。新透明素材采用 BiRefNet。下方关于两年龄、三色叠层的说明是默认旧素材的保留实现；当前整体范围见 [开发推进记录](stargarden/开发推进记录.md) 和 [抠图与音效方案](stargarden/抠图与音效方案.md)。

## 绘制标准

- 90 年代日式养成游戏的手绘感，细棕色轮廓线，少量自然粗细变化。
- 平涂固有色，每种材质以一层清晰、硬边的阴影表现体积；高光克制。
- 象牙白、鼠尾草绿、浅薄荷绿、灰粉色为主，明亮、干净、清新。
- 人物五官柔和，眼睛大小适中，身体比例随年龄自然变化。
- 背景简洁，让人物优先；城镇建筑轮廓清楚，减少花草堆砌和繁密碎细节。
- 避免现代通用亮面动漫、厚重渐变、空气感喷枪、过大萌系眼睛、水彩纹理、颗粒、泛黄与 3D 效果。

## 已确认的角色设计

栗棕色齐肩微卷短发、碎刘海、琥珀棕眼睛、深灰绿发带。象牙白高领泡泡长袖衬衣、灰粉领结、鼠尾草绿背带裙、棕色细腰带、白袜与棕色系带靴；双手拿绿色书本。成年前后的五官与服饰保持可识别的一致性。

幼年默认立绘直接使用获批测试图，不重新生成替代它。少年默认立绘用于 14–15 岁，16–18 岁另有成长立绘。默认服装保留三色配色；新衣装按版型与年龄单独绘制，不计为改色。

## 素材与实现

源图及画风参数见 [art-direction.json](../art-src/stargarden/art-direction.json)。完整生成提示词、模型、接口及时间见 [生成记录](../art-src/generation_log.jsonl)。仍使用用户指定的项目接口，通过 `scripts/genimage.py` 调用。

`npm run assets:raising` 处理原图，使用 Pillow、NumPy、OpenCV，生成 10 张运行时素材，见 `public/assets/stargarden/manifest-cel-v3.json`。原图保持不变，透明蒙版和源图指纹保存在 `art-src/stargarden/cel-v3/masks/`。素材路径统一从 `src/raising/art.ts` 取得。

实际显示顺序如下：

1. `room-cel-v3.webp`：独立空房间背景。
2. `home-cel-v3-body.webp` / `teen-cel-v3-body.webp`：从原图提取的透明人物基础层，保留默认衣装，加载降级时也能完整显示。
3. `*-cel-v3-outfit-{garden,rose,sky}.webp`：只在裙装区域有不透明像素的服装配色层，头发、皮肤、衬衣和书本不随它变色。
4. 独立的姓名、心声气泡、状态与按钮。

主界面用 Phaser 叠加图层，衣橱用相同尺寸的透明图片叠加，共用锚点与比例。切换衣装只改变服装配色层；当前三款是同一版型三种配色。真正的新款式、表情、前后发与手持物需要后续单独绘制相应图层，当前不把这些尚未制作的图层视作已完成。

城镇场景独立使用 `town-cel-v3.webp`。

此前水彩版和通用亮色版源图保留在原位置，仅供对照。
