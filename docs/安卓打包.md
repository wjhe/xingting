# 安卓打包说明

用 Capacitor 6 把网页版装进安卓壳。游戏代码与网页版共用，安卓专有的处理在 `src/platform/android.ts`。

## 一键打包

```
npm run build:android            # 正式签名包 → dist-android/wendao-<版本>-release.apk
npm run build:android -- debug   # 调试包（不需要密钥）
```

脚本依次执行：构建网页 → `npx cap sync android` → Gradle 打包 → 复制 APK 到 `dist-android/`。

## 工具链

不需要单独安装 Android Studio，直接用 Unity 6000.0.23f1 自带的安卓工具：

| 组件 | 位置 / 版本 |
|---|---|
| JDK | `D:/unity/6000.0.23f1/Editor/Data/PlaybackEngines/AndroidPlayer/OpenJDK`（17.0.9） |
| Android SDK | 同目录下 `SDK`（平台 33～35，build-tools 34） |
| Gradle | 8.2.1，第一次构建时从腾讯云镜像自动下载 |

- Capacitor 7 要求 JDK 21，Unity 带的是 17，所以用 Capacitor 6。
- 换电脑或 Unity 版本时，修改 `android/local.properties`（SDK 路径），并设置环境变量 `ANDROID_JAVA_HOME` 指向 JDK 17。
- Maven 依赖走阿里云镜像（见 `android/build.gradle`）。
- 项目路径含中文，已在 `android/gradle.properties` 加 `android.overridePathCheck=true`。如果以后遇到奇怪的资源打包错误，可以把项目挪到纯英文路径再试。

## 签名密钥（重要）

- 密钥在 `android-keys/wendao-release.jks`，密码在 `android-keys/keystore.properties`，整个目录已加入 `.gitignore`。
- **务必把 `android-keys/` 整个目录另外备份**，比如网盘或 U 盘，多存几份。同一个应用的每次更新都必须用同一个密钥签名，密钥丢了就只能换包名重新发布，老玩家无法覆盖升级。
- 证书 SHA-256：`a8003de19fa0c60e7704e19c44ae3406c0b27726d0624b74ca8558dcb35cf741`。部分应用商店和广告平台注册时需要填写。

## 安卓专有处理（src/platform/android.ts）

- **返回键**：按"关菜单 → 回洞府页 → 再按一次退出"的顺序处理，转场播放时忽略返回键。
- **切到后台**：存档并暂停全部声音，回到前台时恢复。
- 状态栏、导航栏用宣纸色配深色图标。

## 安装到手机

1. 手机打开"开发者选项"和"USB 调试"，用数据线连电脑。
2. 执行：`D:/unity/6000.0.23f1/Editor/Data/PlaybackEngines/AndroidPlayer/SDK/platform-tools/adb.exe install -r dist-android/wendao-0.0.1-release.apk`
3. 也可以直接把 APK 文件发到手机上安装（要允许"安装未知来源应用"）。
