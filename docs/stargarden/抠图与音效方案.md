# 抠图与音效方案

日期：2026-11-01。

## 正式新素材的 AI 抠图

本轮新透明立绘使用 **BiRefNet ONNX FP16**，通过本地 ONNX Runtime CPU 推理，不上传到外部抠图服务。模型运行文件约 490 MB，只在素材制作工具中使用，不进入网页产物。

- 模型：[onnx-community/BiRefNet-ONNX](https://huggingface.co/onnx-community/BiRefNet-ONNX)。
- 固定版本：`534d3c82d3bb8b2f0867db6dfbc3a525b8e42f67`。
- 下载的模型卡和仓库元数据标注 `license: mit`，证据保存在 `art-src/stargarden/research/`。
- 下载脚本：`scripts/stargarden-download.py`。网络环境下使用 Hugging Face 镜像获取同一仓库的固定版本。
- 处理脚本：`scripts/stargarden-production-assets.py`。

输入缩放至 1024×1024，按官方预处理均值与标准差归一化，推理后将 logits 经 sigmoid 转为透明度。蒙版恢复原图分辨率，清除近零背景，软边做蓝底颜色去混合。人物统一到 900×1350 画布、约 95% 有效高度；方形敌人使用 900×900。保留蒙版、源图指纹、处理版本与深色底检查图。

新款衣装采用整套透明立绘，保证手臂、披肩、裙摆和帽子的遮挡关系；背景与 UI 仍是独立层。默认获批幼年立绘及原少年立绘继续保留原有已修补蒙版；其旧三色叠层没有被冒称为新款式。16 岁以上的默认立绘和新服装使用新 AI 抠图流程。

本轮已实际采用 BiRefNet；RMBG 尚未部署，不能把候选方案写成已经完成效果对比。质量以导出结果检查为准，不只看模型名称。

检查项：多底色下发梢和发带完整；白衣、手指、腿部、腰带与鞋带无孔洞；裙摆与帽子轮廓连续；背景和地面没有残留。生成 `masks/*-dark.jpg` 辅助检查，浏览器另验证图层加载、透明角点和人物主体存在。

重新处理：

```powershell
python scripts/stargarden-download.py
python -m pip install soundfile --target tools/audio-python --no-deps
npm run assets:raising:production
```

处理依赖 Pillow、NumPy、OpenCV、ONNX Runtime、SoundFile 和 CFFI。模型和本地音频依赖目录已排除在版本库与前端发布文件外。

## CC0 音效

两个素材包均已从官网实际下载，包内 `License.txt` 明确写明 Creative Commons Zero / CC0，并允许商业用途。

| 素材包 | 来源 | 已使用方向 |
|---|---|---|
| Kenney Interface Sounds 1.0 | https://kenney.nl/assets/interface-sounds | 点击、返回、购买、换装、事件、胜利 |
| Kenney Impact Sounds 1.0 | https://kenney.nl/assets/impact-sounds | 木剑命中、受伤打击 |

原始压缩包与来源页面保存在 `art-src/stargarden/research/`，解压素材在 `art-src/stargarden/audio/`。运行文件与授权副本在 `public/assets/stargarden/audio/`，精确文件映射见该目录 `sources.json`。

导出时裁掉多余静音，目标 RMS 约 0.06，峰值限制为 0.7，首尾增加 2 毫秒淡化，输出 OGG Vorbis 与 PCM16 WAV 备用格式。浏览器不支持 OGG 时自动选 WAV。这里记录的是实际振幅处理，不将其称作尚未进行的 LUFS 母带处理。

播放由 `src/raising/sound.ts` 管理：首次交互解锁 Web Audio 上下文，解码后缓存并复用，战斗计时器也通过已解锁的上下文播放；最多四路并发，同类短时间重复限制，后台暂停，音效开关和音量保存。设置里独立调整音效，原有音乐开关继续保留。

AI 背景音乐另见 [AI 音乐需求与提示词](AI音乐需求与提示词.md)，当前未生成七首正式音乐。
