# 日程逐项演出

2026-11-01：将日程完成后的列表弹窗升级为逐项自动播放；最后保留月度总结。

- 上旬、中旬、下旬各自展示活动插画，加入缓慢运镜、光点和状态提示。居家休息场景叠加当前年龄、服装立绘。
- 每项先播放活动过程，再浮现能力、金币及压力变化，自动进入下一项。家庭账本、收获祭及生日依实际结算顺序单独演出。
- 支持 1×、2×、4× 速度；“下一项”在结果未揭示时先揭示收获，再次点击进入下一项；支持直接跳过演出到月度总结。
- 月度总结保留战斗回顾、剧情和结局入口。演出使用已结算的数据，不额外修改金币、属性、随机种子或存档。
- 关闭弹窗、切换弹窗时取消播放；网页进入后台时暂停演出计时；遵循系统减少动态效果偏好。
- 日程采用当月年龄立绘，避免生日后的年龄提前用于生日之前的活动。

当前动态效果是现有插画的运镜和界面动效，并非逐帧角色动作动画。

验证：`npm run smoke:raising:schedule` 覆盖自动顺序、收益揭示、速度、跳过、关闭、结算不重复、收获祭、生日、320/390/430 宽度及减少动态效果。`npm run build` 构建通过。
