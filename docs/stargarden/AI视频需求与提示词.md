## 二、统一规则（每段都必须遵守）

### 2.1 生成方式

- **只用图生视频，不用文生视频**：以下文指定的首帧图作为第一帧，保证画风与游戏一致。
- 如果 Seedance 2.0 支持“首尾帧”，并且下文给了尾帧，就同时使用；不支持时只用首帧，并在提示词里描述结尾状态。
- **不需要声音**：关闭或丢弃视频自带音频，配乐和音效由游戏统一播放。
- 每段生成 3–4 个候选，挑 1 个；落选的也保留，便于以后回看。
- 商用授权以 Seedance 当前条款为准；生成前确认账号类型允许商用。

### 2.2 动作原则

- **镜头慢，动作小。** 优先让环境动（光、风、粒子、热气、窗帘、云、水面），人物只做很小的动作：眨眼、呼吸、发梢飘动、轻微转头。
- **不要大幅移动手和脸。** 这两处最容易变形。需要手部动作的段落，幅度要写得非常小。
- **不出现新人物，不改变服装、发型和发带。** 背景里已有的人物只做极小的动作，或保持不动。
- **画风不能漂移。** 保持 1990 年代日式赛璐璐手绘：棕色细轮廓线、平涂、每种材质一层硬边阴影。不能变成 3D、写实、厚涂或现代亮面动画。

### 2.3 统一提示词后缀（加在每段提示词末尾）

```
保持首帧的画风不变：1990年代日式赛璐璐手绘动画，棕色细轮廓线，平涂色块，每种材质一层清晰阴影，明亮干净的米白、鼠尾草绿、灰玫瑰色调。镜头运动缓慢平稳，人物动作幅度很小且自然。人物的脸、手、发型、发带和服装始终保持与首帧一致，不变形、不换装。
```

### 2.4 统一负面要求（支持负面提示词时填写；不支持时写进正文“避免……”）

```
画风变化，3D，写实，厚涂，水彩颗粒，发光特效过强，脸部变形，五官漂移，手指变形，多余的手指，肢体扭曲，新增人物，服装变化，发型变化，文字，字幕，水印，logo，画面闪烁，快速运镜，镜头抖动，突然切镜
```

### 2.5 交付格式

| 项目 | 要求 |
|---|---|
| 画面比例 | 按每段规定（开场与转场为竖版 3:4，结局为横版 4:3，窗外循环为竖版 2:3 或 3:4） |
| 分辨率 | 至少 720p（短边 ≥ 720 像素） |
| 帧率 | 24 fps |
| 母版 | 生成平台给出的原始文件，放在 `art-src/stargarden/video/<编号>/` |
| 运行文件 | 程序侧负责转码，生成者不必处理 |
| 首帧图 | 每段同时导出视频第一帧为 PNG（`<编号>-first.png`），用于加载前显示，确保静态图切到视频时不跳 |

### 2.6 记录

每生成一个候选，追加一行到 `art-src/stargarden/video/video_log.jsonl`：

```json
{"id":"vid-op-starfall","candidate":1,"file":"art-src/stargarden/video/vid-op-starfall/vid-op-starfall_1.mp4","model":"Seedance 2.0","first_frame":"…","last_frame":null,"ratio":"3:4","duration":5,"prompt":"…","negative":"…","time":"2026-11-05T10:00:00","chosen":false}
```

挑定后把对应行的 `chosen` 改成 `true`，或在同目录写 `chosen.txt` 说明选了哪一个、为什么。

### 2.7 验收清单（每段逐条检查）

- [ ] 第一帧与首帧图一致，没有跳色或跳位置
- [ ] 全程没有脸部、手指、肢体变形，没有人物“融化”或五官漂移
- [ ] 服装、发型、发带、旅行包等道具前后一致
- [ ] 画风始终是平涂赛璐璐，没有变成 3D 或写实
- [ ] 没有文字、水印和新人物
- [ ] 镜头平稳，没有抖动或突然切镜
- [ ] 时长符合要求；需要循环的，首尾能衔接
- [ ] 在手机竖屏上预览过（开场和转场）
