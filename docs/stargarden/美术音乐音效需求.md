- 画风以 `art-src/stargarden/style-tests/cel-v3.png` 为准，提示词前缀使用 `scripts/stargarden-produce.py` 中的 `STYLE`；画到主角时再加上 `CHARACTER`。

## 二、背景音乐（Suno）

### 2.1 Suno 使用说明

- **商用授权**：以 Suno 当前条款为准。一般需要在付费订阅期间生成的作品才可以商用，免费账号生成的不要放进游戏。保留订阅记录和每首歌的生成链接。
- **模式**：打开 Instrumental（纯音乐）；歌词框只写结构标签，不写歌词。
- **Style of Music**：直接复制下表的英文；字数限制较严时，至少保留前两句。
- **Exclude styles**（如果版本支持）：统一填 `vocals, choir, EDM, dubstep, trap, heavy drums, distorted guitar, horror, epic trailer`。
- **主题统一**：先生成 `bgm_home` 并定稿，之后的 `bgm_opening_morning`、`bgm_night`、`bgm_story`、`bgm_growing` 用 Suno 的 Cover / 参考音频功能，以 `bgm_home` 为参考做变奏，让全作有同一个主旋律。`bgm_opening_night` 里的星星动机（钢片琴）之后也会出现在 `jingle_chapter` 和结局里。
- **开场两首要能衔接**：`bgm_opening_night` 结尾留一个安静的长音，便于在第 5 幕交叉淡入 `bgm_opening_morning`；两首都不需要做循环，但要比实际播放时长多留 30 秒，防止玩家读得慢时音乐提前结束（播完后自动淡出到静音）。
- **循环**：Suno 不保证生成的音乐能无缝循环。下载后剪出 60–120 秒的循环段，做交叉淡化，并记录循环起止点；短乐句不需要循环。
- 每首生成 4–6 个版本，挑选标准：旋律好记、没有突然的鼓点或音量跳变、长时间听不累。

**歌词框统一模板（BGM）**

```
[Instrumental]
[Intro]
[Main Theme]
[Variation]
[Bridge]
[Main Theme]
[Outro - soft, loopable]
```

**共同风格前缀**（加在每首 Style 的最前面）：

```
instrumental, cozy Japanese life-sim game soundtrack, 1990s SNES/PC-98 era warmth, small acoustic chamber ensemble,
```

### 2.4 交付与接入

- 交付 WAV 母版（44.1/48 kHz）；运行时转 OGG，并准备 AAC 备用。背景音乐响度约 −20 LUFS，短乐句约 −16 LUFS，真峰值不高于 −2 dBTP。
- 切换场景时做 0.6–1 秒淡入淡出；同一首曲子不因界面刷新而从头播放。播放短乐句时，背景音乐临时压低 6 dB。
- 设置里的“庭院音乐”开关改名为“背景音乐”，并替换掉现在的合成旋律。

## 三、音效

### 3.1 规则

- 工具：AI 音效生成器（例如 ElevenLabs Sound Effects、Stable Audio 等），用下表的英文描述，一次生成 4 个版本挑 1 个。
- 风格：**柔和、干净、像木头、纸张、铃铛和布料发出的声音**。避免电子哔声、刺耳高频和夸张的爆炸声；战斗音效也保持“轻快冒险”，不要血腥感。
- 格式：48 kHz WAV 母版，转 OGG 使用。单次音效峰值不高于 −3 dBFS，同一类音效之间音量要一致；开头不能有空白，结尾自然衰减。
- 记录每个音效的工具、提示词、生成时间和使用条款；替换现有 Kenney 音效时，保留 `sources.json` 的来源记录。
