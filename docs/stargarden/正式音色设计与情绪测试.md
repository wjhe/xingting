# 正式音色设计与情绪测试

2026-11-04，按用户指定的官方音色设计接口准备测试。

官方文档：https://docs.volcengine.com/docs/doubao-voice/sound-design-api?lang=zh

## 必要配置

`POST /api/v3/tts/voice_design` 的 `speaker_id` 为必填字段，文档说明为“唯一音色代号，控制台购买”。API Key 不会代替这个字段，也不会自动购买或分配音色。

项目根目录提供 `音色设计配置.example.json`，填写一个闲置的、实际购买的 `S_` 音色代号后另存为 `音色设计配置.json`。后者已加入 Git 忽略。认证沿用用户提供的 `音频生成key.txt`。

## 测试流程

运行 `python -X utf8 scripts/stargarden-voice-design-test.py`：

1. 先通过 `/api/v3/tts/get_voice` 检查音色状态，仅在未训练状态执行设计，防止覆盖已有声音。
2. 设计一位10岁女儿的清亮、自然、柔和普通话声音，保留设计提示与状态记录。同一次设计不自动重试。
3. 音色就绪后，在音频生成接口 `/api/v3/tts/create` 中以同一个 `references.speaker` 生成平静、开心、难过、认真四条相同台词。
4. 四条试听统一音量，保存原始音频与完整参数，生成对比试听页。

情绪方式为 `seed-audio-1.0` 的自然语言提示控制，不冒充 TTS 的结构化 emotion 参数。当前官方 HTTP TTS 文档将 `context_texts` 限定于指定内置音色，不能直接承诺设计音色支持同一套指令。
